A **24/7 unattended** monitoring system for multiple streaming platforms.

## ✨ Key Features

### 🎯 Multi‑Platform Coverage
- Monitors **5+ major streaming platforms** at once  
- Unified pushes, unified management – no app‑switching needed

### 🤖 AI‑Powered Filtering
- **Face detection** – clear faces only  
- **Pose evaluation** – captures engaging body language  
- **Image quality analysis** – filters out blurry, dark, or static frames  
- Only pushes **high‑quality newcomers** – no spam

### ⚡ Instant Delivery
- Receive notifications **within minutes** of a new streamer going live  
- Each push includes: **high‑resolution screenshot + live room link + one‑tap share button**  
- Supports both **Telegram channels and groups**

### 📊 Easy Management
- Check **daily summaries, missed candidates, system status** via simple Telegram commands  
- Auto‑generated **daily digest image** – see everything at a glance
